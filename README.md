# MA Compass

Google広告・Yahoo!広告・Meta広告・Search Console・GA4・SNS・AI検索などを **1 つの共通データモデル** に集約し、カスタマージャーニーから「誰に・何を・どこで届けると成果が出るか」を可視化して、戦略立案から施策実行・効果検証までを行う統合マーケティング基盤です。

既存の 5 ダッシュボード（GA / Google広告 / SEO / SEO・GEO・AIO・LLMO / SNS）を作り直さずに取り込み、企業ごとに必要なチャネルを後から追加できるモジュール構造になっています。

## 画面

| 画面 | できること |
|---|---|
| 支援先一覧 | 支援しているすべての企業の KGI 達成率・要対応事項を並べ、対応が必要な順に表示 |
| 経営戦略 | strategy-agents の戦略カーネル・KGI・シナリオ、トリップワイヤーの実績監視、チャネル配分の計画 vs 実績、100日プランの起票 |
| 連携ハブ | 6 ツールの出力（JSON）を形式自動判別で取り込み |
| コマンドセンター | KGI 達成率、全チャネル KPI、日別推移、チャネル別成果、ファネル、異常検知アラート、注目インサイト |
| カスタマージャーニー | 段階×チャネルのフロー図（顧客の動きをアニメーション表示）、段階別離脱、CV 経路、アトリビューション 5 モデル比較 |
| オーディエンス分析 | セグメント × チャネル / 訴求軸の CVR 指数ヒートマップ、推奨アクション、勝ちパターン |
| 戦略プランナー | KGI から逆算した KPI ツリー、応答曲線による予算シミュレーターと最適配分 |
| 施策ボード | 企画〜完了のカンバン（ドラッグ＆ドロップ）、インサイト・分析からの起票 |
| AIインサイト | 予算再配分・異常・勝ちパターン・非効率・SEO 上位化・AI検索引用・評価の偏り・離脱・未導入チャネルの提案 |
| チャネル別ページ | 有効モジュールごとに自動生成。概要 / 既存ダッシュボード（埋め込み）/ データ連携（JSON・CSV 取り込み） |
| モジュールカタログ | モジュールの追加（接続ウィザード）、カスタムモジュール作成 |
| 設定 | 企業情報・KGI・予算・セグメント、企業の追加・削除 |

サンプル企業（架空）：ネクサラーニング株式会社（BtoB 研修）、ルミエールスタイル（アパレル EC）、さくら通り歯科クリニック（地域ビジネス）。

## 開発

Node.js 22 以上。

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 分析エンジンの単体テスト（Vitest）
npm run typecheck  # 型チェック
npm run build      # 本番ビルド（dist/）
npm run build:demo # 共有用の単一 HTML デモ（artifact/ma-compass.html）

# strategy-agents のプロジェクトを取り込み用 JSON に書き出す
node scripts/export-strategy.mjs <strategy-agents>/projects/<id> strategy-plan.json
```

## ディレクトリ構成

```
src/
  core/
    types.ts            共通データモデル（UMDM）
    constants.ts        ジャーニー段階・訴求軸・指標定義
    data/               サンプル生成・データセット・ブリッジ取り込み・サンプル企業
    analytics/          集計・ジャーニー・アトリビューション・セグメント行列・異常検知・予算最適化・インサイト・戦略連携
    connectors/         既存 6 ツールの出力を取り込むコネクタ
  modules/              モジュール定義（1 モジュール = 1 マニフェスト）とレジストリ
  store/                状態管理（Zustand、ブラウザ保存）
  components/           UI 部品・チャート・ウィジェット
  pages/                画面
tests/                  単体テスト
docs/                   設計書・要件定義書・機能仕様書・ガイド
```

## MVP の範囲

- データはシード固定のサンプルデータ、またはブリッジ（JSON/CSV）取り込み。OAuth による自動取得は Phase 2（BFF 導入後）。
- カスタマージャーニーの経路は集計データからの推定。Phase 2 で GA4 の BigQuery エクスポート等の実経路に置き換え。
- インサイトはルールベース。Phase 2 で生成 AI による文章化・質問応答を追加。
- 認証・権限・監査ログは Phase 2。現在はブラウザ内保存（localStorage）で単一利用者を想定。
